A full-stack, dual-layer web platform designed to streamline operations, event pipelines, and communication for the Science and Innovation Club. Featuring a modern, interactive Claymorphism design system.

## ✨ Core Features

* **Dual-Layer Access:** Dedicated dashboards for General Students and Core Members.
* **Seamless Authentication:** Secure login and session management powered by Supabase Auth.
* **Interactive UI:** Visually engaging Claymorphism aesthetics built with Tailwind CSS.
* **Real-Time Communication:** Integrated member chat functionality and dynamic notification pipelines.
* **Event Pipeline:** Comprehensive event and project management system.
